## Установка и запуск

1. Настройте `.env`:

```bash
touch .env
```

```
BOT_TOKEN=токен_бота
```

2. Запустите бота:
```bash
docker compose up -d
```

## Просмотр логов

```bash
docker compose logs -f
```

## Управление пользователями

Для добавления пользователей отредактируйте файл `allowed_users.json`. Бот автоматически подгрузит изменения при следующей итерации проверки цен.

```bash
nano allowed_users.json
```

## Настройка параметров

В файле `bot.py` вы можете изменить следующие параметры:
- `SMALL_PUMP_THRESHOLD` - порог для небольших движений цены (по умолчанию 5%)
- `BIG_PUMP_THRESHOLD` - порог для сильных движений цены (по умолчанию 10%)
- `MONITORING_INTERVAL` - интервал проверки цен (в секундах)
- `MIN_VOLUME_24H` - минимальный объем торгов за 24 часа (в USD)

## Обновление бота

Для обновления бота выполните:
```bash
# Остановка текущего контейнера
docker compose down

# Получение обновлений
git pull

# Пересборка и запуск
docker compose up -d --build
```
